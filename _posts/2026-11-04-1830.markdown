[The beleaguered Galway ring road project](https://progressireland.substack.com/p/galway-should-get-its-ring-road), which will run relatively close to my house, should finally start construction next year. It got approved for outlasting the objectors rather than the strength of any particular vision, but there's still time to add one! I can see this becoming a test case for whether Ireland can build things.
